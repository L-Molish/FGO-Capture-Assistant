PaperMoon v2.3.10 使用说明

一、版本亮点（v2.2.5 ~ v2.3.10）
- 修复雷电共享 NAT 端口冲突与防误连（v2.3.10）：雷电 9 / 14 共享 NAT 改为会话级 127.0.0.1 动态回环转发，先核验 VM 归属、DHCP 租约与 VBox NAT 监听进程，连接后再核对安卓版本与网卡 MAC，避免误连其他模拟器或被占用的 5555 端口；结束、失败或取消时先恢复设备网络再断开并清理自建转发，不改动原 5555 与第三方规则。另修复数据报告生成长图失败：浏览器临时未返回页面时会有限重试，并区分浏览器退出、空页面、缺少高度等原因；不再一律提示「没有回报自身高度」。
- 报告更快更清晰（v2.3.9）：换御主服从约 9 秒降到约 3 秒，弹窗能看全礼装名和等级、选中有蓝框；数据报告按 2 倍分辨率渲染，高分屏上文字和图标不再发虚。
- 修复台服卡在标题页（v2.3.8）：台服标题页那行「Touch Screen」是英文艺术字，走中文识别读不出来，自动登录会一直停在标题页不动。现在不再依赖文字识别，改用它的固定位置、浅青蓝色和呼吸式闪烁三个特征来判断。另外两个问题也一起修了：MuMu 自带的加速服务弹窗会挡住游戏，现在自动选「不加速」；安卓上报的焦点窗口首行为空时，自动登录以前会一直不点击，现在能正确识别。
- 支持 OPPO / 华为 / 台服（v2.3.7）：国服渠道新增 OPPO 与华为两个渠道服，与九游、小米等渠道走完全相同的抓包流程，在「渠道」里选中或用自动识别即可。新增台服（小萌代理版本）区服支持：实测台服不需要加速器或代理，程序按国服一样的直连方式抓取，首次启动要下载较多资源，等游戏进入标题画面后再开始抓包。同时修复两个会导致抓包卡住的问题：MuMu 自带的「加速服务」弹窗会挡住游戏，现在会自动选择「不加速」；以及 Android 上报的焦点窗口首行为 null 时自动登录从不点击。
- 更名 PaperMoon（v2.3.6）：程序更名为 PaperMoon（ペーパームーン / 纸月，型月里那台把高维世界压成平面、统一坐标的虚数观测装置），窗口标题、报告页脚与文件属性同步更新，图标改为原圣晶石图案的矢量化版本 + 浅灰圆角底，小尺寸更清楚；抓包、统计与攒石规划功能不变，已有设置与历史抓包继续沿用。
- Q 版立绘与手动选目录（v2.3.5）：攒石规划那张 Q 版立绘其实是热情迷唇（Passionlip），标注与文件名已改正，国服资料里该从者的名字也从英文改成「热情迷唇」；手动选目录时选到安装目录下面的 shell、device 等中间层也能识别，对话框标题已写明是选文件夹。
- 从者名显示（v2.3.4）：日服资料里的「メルトリリス」以前会被翻成「メルト莉莉丝」，国服资料里则是英文 Meltryllis，现在统一显示官方译名「溶解莉莉丝」。
- MuMu 识别与残留代理（v2.3.3）：新版 MuMu 12 的管理器在 `shell` 目录下也能自动识别，手动选择安装根目录或 `shell` 这一层都可以；模拟器里残留的旧代理会自动清除后再开始抓包，抓包结束时不再把这些残留值写回去。
- 攒石规划可用性（v2.3.2）：登录响应里没有礼物盒数据时，攒石规划不再拒绝打开，按空礼物盒继续计算；攒石资料更新新增镜像回退（gh-proxy / ghfast / ghproxy.net），直连 GitHub 不通时也能更新；更新失败的提示会写明当前实际使用的资料日期。
- 修复雷电 9 代理地址选择（v2.3.1）：修复部分用户在雷电 9 上「环境检查全部通过、游戏却一直提示连接失败」的问题。此前程序可能把设备代理指向电脑上 Clash、Tailscale、加速器等虚拟网卡的地址，链路依赖这些隧道的状态；现在优先使用模拟器网关与本机真实网卡，虚拟网卡仅作兜底，并在日志中打印实际使用的代理地址。
- 支持国服渠道服（v2.3.0）：新增九游、小米、vivo、4399、应用宝渠道服抓包；B服、享游安卓与 iOS 账号使用同一安装包。抓包页国服可选择「渠道」，默认自动识别正在运行的渠道；同时安装多个渠道且都未运行时，请先打开要抓的那个，或在「渠道」中手动选择。同时给「终止」增加了兜底：任务进程意外消失或长时间无响应时，界面会自动收尾恢复可用，不再需要强制关闭程序。
- 修复自动更新重启报错（v2.2.11）：修复单文件程序在自动更新替换后重启时继承 _MEI 环境变量导致 Failed to load Python DLL 的问题。（该修复由发起更新的程序执行，因此从 v2.2.10 及更早版本升级到本版本时，这次重启仍可能弹出一次相同报错，重新打开程序即可；此后更新不再出现。）
- 自动更新多源回退（v2.2.10）：当直连 GitHub API 或下载节点受阻时，自动回退至 jsdelivr 与 GitHub 加速镜像检查最新版本并下载安装包，且强制校验 SHA256SUMS.txt 与可执行文件头。
- 自动检查更新与界面优化（v2.2.9）：启动后自动在后台检查 GitHub 最新正式版，有更新时左下角「检查更新」图标亮起蓝点并在标题栏显示「更新到 vX.X.X」胶囊按钮；点击可查看更新内容、带进度条下载、自动校验 SHA-256 并一键重启替换。同步优化了结果提示弹窗与更新弹窗样式，并将「绑定模拟器」成功标记改为绿色。
- 攒石资料可单独更新（v2.2.8）：点「更新资料」会同时刷新国服统计资料、日服统计资料和攒石资料，不必等新安装包；活动签到与纪念奖励补齐到日服 2026-11-18（国服预测 2027-11-18），2027 年 8 月中旬之后的攒石目标不再漏算活动收入。
- 出货率与模拟器识别修复（v2.2.7）：随包统计资料刷新到最新，修复部分国服用户「统计」页五星出货率显示为“--”的问题（旧资料认不出图鉴里的新记录时，程序会为避免算错而隐藏出货率）；同时修复雷电模拟器自动检测：部分雷电 9 / 14 的注册表只登记了 DisplayIcon、没有安装路径，以前可能检测不到，现在会自动识别。
- 自动登录稳定性修复（v2.2.6）：优化标题画面「点击屏幕」闪烁容差与快速复查补点（2.5 秒间隔），解决点击标题登录提示后卡顿的问题；增强 Windows OCR 引擎回退并在系统缺少 OCR 组件或连续识别失败时优雅暂停自动点击、继续保持抓包等待（不再抛出 RuntimeError 中断抓包）。
- 攒石规划与界面优化（v2.2.5）：
在“统计”页读取完整国服登录抓包后，可切换至“攒石规划”：
- 目标卡池与预览：采用 Mooncell 卡池命名与最新卡池列表，支持关键词模糊搜索与快速下拉选择；展示卡池横幅与 UP 从者头像（点击或悬停可查看从者名称，点击“+N 位”可查看其余 UP 从者；期间限定从者为红色边框、剧情限定从者为蓝色边框）。
- 自定义日期与双口径预测：内置与整体界面风格一致的年/月/日网格日历选择器；两张卡片分别显示“开池当天可用”与“梦火全刷后”的“召唤×N次”抽数及圣晶石、呼符明细；月表按月列出新增资源与累计余额。
- 自动计算规则：自动核对活动赠送、关卡首通、限时/额外/御主任务、月商店、梦火与大梦火，无需手工补奖励。默认不断签、期间不花石、可达任务和养成尽早完成、商店换满。预测资料随「更新资料」滚动，当前覆盖至 2027-11-18（未来国服档期按日服平移一年，非国服官方公告）。
- 额外情景与收支明细：默认不计入尚未公布的国服维护与地区宣传，可勾选“计入日服宣传同额预测”查看额外情景；两个目标独立起算，不扣除另一卡池花费。点击“查看收支明细”可分别查看“常驻可榨干明细”与“后续时间绑定明细”两大板块，并支持实时关键词筛选；未持有从者、互斥路线、当前不可达任务及目标日之后奖励不计入。
- 统计与报告优化：圣晶石、呼符、梦火均采用高清图标×数量展示；“导出统计长图”移至“数据报告”页；“更新资料”同时更新国服／日服统计资料与攒石资料。

二、运行与升级
运行 EXE，放在可写文件夹即可，无需安装 Python 或 Reqable。Windows 可能提示未知发布者，可与随附 SHA256SUMS.txt 核对文件。
升级时可放回原程序目录，沿用已有设置、公开统计资料、本机证书和 results 中的历史数据。

三、支持范围
- MuMu 安卓 12、15 ROOT 实例共用同一程序和操作流程。
- 支持雷电 14（安卓 14）、雷电 9（安卓 9）ROOT 实例。
- MuMu 安卓 12、雷电 14、雷电 9 的国服已实测普通网络、FlClash 和 biubiu 开启时抓包。日服已实测雷电 14 普通网络，其加速器环境及 MuMu 安卓 12、雷电 9 日服待测。MuMu 安卓 15 已验证国服完整抓包及重启后自动恢复证书。
- 自动检测会列出 MuMu 和雷电实例，显示模拟器及安卓版本。未找到时，点击“手动选择（备用）”，选择 MuMu 或雷电的安装文件夹，再刷新列表。
- 雷电 9 和雷电 14 的相同编号实例请逐台运行，避免模拟器本身的 ADB 编号冲突。选择目标后再操作，勿在任务期间切换或关闭模拟器。
- 修复 MuMu 与雷电同编号实例的 ADB 串连：雷电使用独立回环地址，并在连接后核验实际安卓版本。先启动游戏再测游戏网络，避免安卓 15 对未启动游戏的后台联网限制造成误报。

四、取得完整登录响应
检查未通过时，主界面会逐项列出失败项目、具体原因和处理方法。初始化或抓包失败时会显示失败阶段和完整原因。
1. 选择国服或日服和目标模拟器，确认已安装对应区服的游戏。
2. 点击“初始化环境”，再点“检查环境”。助手会检查并开启所选实例的 ROOT；仅在开启 ROOT 需要生效时重启该实例。无需手动修改雷电配置或安装兼容工具，普通网络抓包及证书安装不需要 KernelSU。
3. 首次初始化会安装并核验本机公开 CA。助手按实际存在的证书库处理：旧安卓使用系统证书库，现代安卓同时核验 Conscrypt 证书库。无需手动导入证书，不修改系统分区。证书使用运行时挂载；模拟器重启后直接点“开始抓包”，助手会自动恢复并核验，已受信任时跳过安装，无需为证书重复初始化。
4. 点击“开始抓包”，助手会重新启动所选游戏，自动点击“请点击游戏界面”和标题登录提示，取得统计数据后立即停止点击。已登录账号无需再手动点登录，也无需先从主界面返回标题。首次账号登录、验证码或协议确认由本人完成，之后助手继续自动识别。可用“终止”停止等待与自动点击。
5. 成功后，磁盘文件和剪贴板得到相同的完整登录响应正文，不裁剪字段、不重编实例编号。文件名为 toplogin_时间戳.json。国服新文件在程序目录的 results/CN 下，日服在 results/JP 下。旧版 results 根目录中的国服文件保持原位，“读最新”仍可读取。移动文件时请一并移动同名 .origin 区服标记。抓包结束或终止后，程序恢复本轮临时设置的代理和转发。成功后任务栏图标闪烁提醒；后台完成不抢前台，切回助手后显示结果详情。
6. 日服日文加载提示使用固定文字图样辅助识别，无需另装日文 OCR。同一账号引继到另一设备后，原设备无法继续登录；多台测试需逐台完成引继并抓包。出现“引き継ぎ完了”时请先恢复该设备的有效账号，勿选择删除用户 ID 并新建游戏。

五、FlClash、biubiu 与网络地址
先在所选模拟器内配置并启动加速器，再按上述步骤抓包。FlClash 建议使用匹配模拟器架构的 x86_64 包，配置和节点需自行准备。
国服自动抓包在加速器开启时仍使用电脑出口。已验证 FlClash 本地 HTTP 转发链路，但当前国服界面不会自动切换到这条路径；biubiu 测试确认的是开启加速时仍可抓包，不表示被抓请求经 biubiu 出口。
MuMu 开启 biubiu 时，默认电脑映射地址可能被 VPN 阻断。助手会以游戏身份实际探测，并自动回退到可访问的电脑本机地址，无需手工修改代理。若所有地址都不可达，请检查 Windows 防火墙是否允许本程序，或停止模拟器加速后重试。
biubiu 同一账号在不同模拟器上同时加速可能互相断开，请逐台测试。切换网络或加速器后重新“检查环境”。

自动登录使用 Windows 内置的本地文字识别，临时截图识别完即删除，不保存到结果目录。若系统缺少相应语言的文字识别组件，日志会提示在 Windows 语言设置中补齐后重试。自动操作仅限游戏启动、加载完成和标题登录提示。

六、统计与报告
在“统计”页选择与文件一致的区服，用“读最新”或“打开文件”读取。可以按卡池查看抽数、五星数和出货率，也可查看从者、羁绊、关卡、资源及数据报告，并在“数据报告”页导出 PNG 长图。新增卡池或从者未收录时，可点击“更新资料”。

七、文件兼容性与隐私安全
v2.2.4 起恢复完整登录响应输出。文件与剪贴板保留服务器返回的完整正文，不做字段筛选、编号替换或 JSON 重新序列化。国服正文可能是经过 URL 转义的 Base64，日服通常为 JSON；本助手和 Chaldea 都可直接读取，不必自行解码或修改文件。
在 Chaldea 中进入“导入 → Https抓包”，选择“从剪贴板导入”；或选择“从文件导入”，打开本次生成的 toplogin_时间戳.json。不要把 results 文件夹路径粘贴到导入入口；复制过其他文字后可直接使用文件导入。
完整响应保留服务器返回的账号标识、签名等字段，请在本地保管，不要公开分享。程序不保存请求内容、失败响应正文或额外的解码副本。
