FGO抓包助手 使用说明

本软件用于在 Windows 上配合 MuMu 模拟器安卓 15 版，抓取 FGO 国服 B 服登录时的 toplogin 数据。
第一次使用需要完成环境初始化；同一个模拟器配置成功后，以后通常只需点击“开始抓包”。


一、使用前准备

1. MuMu 模拟器必须是安卓 15 实例，并已开启 ROOT。
2. 模拟器内需要安装 KernelSU 和 FGO 国服 B 服。
3. 请先在 FGO 中准备好需要抓取的账号。账号登录、验证码和游戏内弹窗仍需本人操作。
4. 建议将 FGO抓包助手.exe 放在单独的可写文件夹中运行。程序会在同目录保存设置、下载文件和抓包结果。
5. 不要将程序放在压缩包内直接运行，请先完整解压。


二、第一次使用

1. 双击 FGO抓包助手.exe，同时启动需要使用的 MuMu 安卓 15 模拟器。
2. 软件默认会自动寻找 MuMu 安装路径，不需要手动设置。
3. 点击“刷新列表”，然后在“目标模拟器”中选择需要抓包的实例。
4. 可以先点击“检查环境”查看当前状态。该按钮只做检查，不会修改模拟器。
5. 点击“初始化环境”，耐心等待日志提示“环境准备完成”。

初始化会自动完成以下准备：
- 等待模拟器启动并获取 ADB ROOT。
- 安装或启动 Reqable，并完成首次工作模式设置。
- 导出、安装并核验当前 Reqable 根证书。
- 按需重启所选模拟器。
- 完成 Reqable 的 VPN 和通知授权，并在验证后关闭测试 VPN。

初始化过程中请不要关闭软件或模拟器，也不要手动启动 FGO。部分设备可能出现系统弹窗或游戏首次登录弹窗；如果程序明确提示需要处理，按照当前画面完成后再继续。

6. 显示“环境准备完成”后，点击“开始抓包”。
7. 程序会自动启动 Reqable 和 FGO。正常完成 FGO 登录，并手动处理可能出现的公告、CG 选择或其他游戏弹窗。
8. 检测到 toplogin 后，程序会提示抓包完成，并自动保存文件和复制响应体内容。


三、以后再次抓包

已经成功初始化过的同一个模拟器实例，不需要每次检查或初始化：

1. 启动 FGO抓包助手.exe。
2. 选择目标模拟器。
3. 直接点击“开始抓包”。
4. 完成 FGO 登录，等待抓包完成。

只有在更换新模拟器、重装 Reqable、重置系统或授权、证书失效时，才需要重新点击“初始化环境”。


四、在 Chaldea 中导入

方法一：从剪贴板导入

1. 抓包成功后不要复制其他内容，以免覆盖剪贴板。
2. 打开 Chaldea，进入“导入” -> “Https抓包”。
3. 选择“从剪贴板导入”。
4. 按提示选择国服，即可读取数据。

程序复制到剪贴板的是 toplogin 响应体文字，不是文件快捷方式。如果 Chaldea 提示剪贴板为空，可以改用下面的文件导入方式。

方法二：从文件导入

1. 点击软件中的“打开结果文件夹”，或打开程序同目录下的 results 文件夹。
2. 选择名称类似 toplogin_日期_时间.json 的原始文件。
3. 不要选择文件名带 _decoded.json 的解码文件；Chaldea 需要的是不带 _decoded 的原始响应体文件。


五、查看软件内的抽卡统计

1. 切换到“抽卡统计”页。
2. 点击“读取最新结果”，即可读取刚刚抓到的数据。
3. 也可以手动打开已有的 toplogin 或 decoded JSON 文件。

统计会显示五星从者出货率、卡池抽数等信息。统计过程完全在本地完成，不会启动模拟器或重新抓包。

统计口径说明：
- 五星从者出货率采用与 Chaldea 历史汇总相近的口径。
- 每个已识别福袋会扣除一个保证五星位置。
- 剧情池会计入整体统计，并在卡池明细中显示抽数。
- toplogin 提供的是账号历史汇总数据，不是完整逐抽记录；部分自选五星等情况可能影响结果，因此统计仅供参考。
- 若需要梦火、圣杯、关卡记录等更完整的报告，建议将结果导入 Chaldea 查看。


六、按钮与暂停功能

- 检查环境：只读检查，不进入证书页面，不修改配置。
- 初始化环境：完成首次使用所需的 Reqable、证书和授权配置，不启动 FGO。
- 开始抓包：在已配置好的环境中启动 Reqable 和 FGO，等待登录数据。
- 暂停：检查、初始化或抓包运行时，可以点击日志区右上方的“暂停”。按钮变为“继续”后可恢复，暂停时间不会计入等待超时；已经发出的短命令可能会先执行完成。


七、MuMu 路径检测

软件优先自动检测 MuMu 路径。只有自动检测失败时，才使用“手动选择（备用）”：

1. 点击“手动选择（备用）”。
2. 选择 MuMu 安装文件夹，或安装目录中的 nx_main 文件夹。
3. 点击“刷新列表”，重新选择目标模拟器。

手动路径会保存在程序旁的 settings.json。点击“恢复自动检测”可以清除手动设置。将软件分享给别人时，不要附带自己的 settings.json。


八、常见问题

1. 找不到模拟器
确认使用的是 MuMu 安卓 15，并先启动模拟器；点击“刷新列表”。仍无法识别时再手动选择 MuMu 路径。

2. 新模拟器点击抓包后提示配置未完成
返回主界面，先点击“初始化环境”，等待全部准备完成后再抓包。

3. 抓包一直等待
确认已经进入 FGO 登录流程。程序需要捕获登录时产生的 toplogin 请求；只停留在游戏主界面可能不会产生新的登录数据。

4. Chaldea 显示 Clipboard is empty
剪贴板可能被其他软件覆盖。请使用 results 文件夹中不带 _decoded 的原始 toplogin 文件导入。

5. Reqable 页面与提示不一致
不要随意点击未知按钮。先查看软件日志；必要时关闭当前任务，重新执行“初始化环境”。

6. 初始化后模拟器自动重启
这是安装 Reqable 证书模块后的正常步骤，请等待程序自动重新连接。


九、数据与发布注意事项

- 抓包结果会保存在程序同目录的 results 文件夹，其中包含账号游戏数据，请勿发送给不可信的人。
- 原始响应体在抓包完成后会进入 Windows 剪贴板，使用完毕后可以复制其他普通文字将其覆盖。
- 本软件不使用 OpenAI、Claude、Gemini 等 AI 服务，也不需要 AI API Key。
- 软件不会主动上传抓包结果；Reqable 安装包会从 Reqable 官方地址下载。
- 对外分享时，只发布 FGO抓包助手.exe、这份使用说明以及教学视频。不要打包 results、settings.json、captures、downloads 或其他个人运行数据。


最简操作流程

首次使用：启动模拟器 -> 选择实例 -> 检查环境（可选）-> 初始化环境 -> 开始抓包 -> 登录 FGO。

以后使用：启动模拟器 -> 选择实例 -> 开始抓包 -> 登录 FGO。
